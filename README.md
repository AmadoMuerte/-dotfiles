# Desktop Configuration (Hyprland)

Hyprland uses native Lua. The desktop stack remains unchanged.

## Structure

```text
~/.config/hypr/
├── hyprland.lua              # entrypoint, applications and bindings
├── monitors.lua              # generated by nwg-displays
├── config/
│   ├── colors.lua            # generated by matugen
│   ├── input.lua
│   ├── appearance.lua
│   ├── animations.lua
│   ├── windowrules.lua
│   ├── workspaces.lua
│   └── autostart.lua
├── hyprlock.conf
└── hypridle.conf
```

Applications are defined once at the top of `hypr/hyprland.lua`. Bindings are
in the same file; appearance, rules and autostart are under `hypr/config/`.

## Important Bindings

| Keys | Action |
|---|---|
| `SUPER+T` | Ghostty |
| `SUPER+E` | Nautilus |
| `SUPER+A` | Fuzzel |
| `SUPER+SHIFT+S` | screenshot region to Swappy |
| `SUPER+L` | lock |
| `SUPER+SHIFT+W` | wallpaper picker |
| `SUPER+SHIFT+V` | clipboard history |
| `SUPER+1..0` / `SUPER+SHIFT+1..0` | switch / move workspace |

## Monitors

Run `nwg-displays`. Version 0.4.3 writes both legacy `monitors.conf` and native
`monitors.lua`; Hyprland loads only `monitors.lua`. Current layout:

- `DP-1`: `2560x1440@180`, position `0x0`, scale `1`
- `DP-2`: `2560x1440@180`, position `2560x0`, scale `1`

## Theme

`matugen` generates `hypr/config/colors.lua` plus the existing Waybar, SwayNC,
GTK, Qt, Ghostty and btop palettes. Run `apply-theme.sh` after changing the
wallpaper. The main Hyprland config is never generated.

## Reload and Debug

```sh
Hyprland --verify-config -c ~/.config/hypr/hyprland.lua
hyprctl reload
hyprctl configerrors
hyprctl systeminfo
```

Rollback copy: `~/.config/hypr-backup-20260828-161703/`.
