# Desktop Configuration (NixOS + Hyprland)

Hyprland uses native Lua. Nix selects and installs complete desktop themes;
application behavior remains in the existing per-application configuration.

## Structure

```text
~/.config/hypr/
├── hyprland.lua              # entrypoint, applications and bindings
├── monitors.lua              # generated by nwg-displays
├── config/
│   ├── theme.lua             # generated by desktop.theme
│   ├── input.lua
│   ├── appearance.lua
│   ├── windowrules.lua
│   ├── workspaces.lua
│   └── autostart.lua
├── hyprlock.conf
└── hypridle.conf
```

Applications are defined once at the top of `hypr/hyprland.lua`. Bindings are
in the same file; appearance, rules and autostart are under `hypr/config/`.

## Important Bindings

| Keys | Action |
|---|---|
| `SUPER+T` | Ghostty |
| `SUPER+E` | Nautilus |
| `SUPER+A` | Fuzzel |
| `SUPER+SHIFT+S` | screenshot region to Swappy |
| `SUPER+L` | lock |
| `SUPER+SHIFT+W` | wallpaper picker |
| `SUPER+SHIFT+V` | clipboard history |
| `SUPER+1..0` / `SUPER+SHIFT+1..0` | switch / move workspace |

## Monitors

Run `nwg-displays`. Version 0.4.3 writes both legacy `monitors.conf` and native
`monitors.lua`; Hyprland loads only `monitors.lua`. Current layout:

- `DP-1`: `2560x1440@180`, position `0x0`, scale `1`
- `DP-2`: `2560x1440@180`, position `2560x0`, scale `1`

## Themes

Theme selector:

```nix
# ~/nixos-config/configuration.nix
desktop.theme = "openbsd-dark";
```

`nix/themes/default.nix` discovers each theme directory. Home Manager installs
selected user configuration. `openbsd-dark/colors.nix` is its shared
palette. Application modules generate Hyprland, Waybar, Ghostty, Fuzzel,
SwayNC, GTK, Hyprlock, and Fish theme files from that palette.

Home Manager is pinned in `nix/configuration.nix` and integrated as a NixOS
module. `nix/home.nix` contains stable per-user settings. The wrapper imports
existing `/etc/nixos/configuration.nix`. The live config lives in
`~/nixos-config`; the old duplicate `~/.config/nix` is archived in
`~/.config/nix-backup` and is no longer used. Build or apply everything with:

```sh
sudo nixos-rebuild build --flake $HOME/nixos-config#nixos
sudo nixos-rebuild switch --flake $HOME/nixos-config#nixos
```

Then log out and in so GTK/session variables and fonts refresh. Running apps
can instead be reloaded with `hyprctl reload`, `killall -SIGUSR2 waybar`, and
`swaync-client -R`.

To add theme, copy `nix/themes/openbsd-dark/` to a new directory, replace its
palette and application outputs, then select directory name. No registry edit
is needed.

Matugen no longer writes files owned by `desktop.theme` and has no active
output templates. `SUPER+SHIFT+W` changes wallpaper without recoloring the
selected desktop theme; next session restores its solid background.

## Reload and Debug

```sh
Hyprland --verify-config -c ~/.config/hypr/hyprland.lua
hyprctl reload
hyprctl configerrors
hyprctl systeminfo
```

Rollback copy: `~/.config/hypr-backup-20260828-161703/`.
